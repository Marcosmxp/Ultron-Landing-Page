# Changelog

All notable changes to Ultron Landing are documented here.

This project follows [Semantic Versioning](https://semver.org/):

- **MAJOR**: incompatible structural/product changes.
- **MINOR**: new sections, interactions, experiments or conversion features.
- **PATCH**: fixes, copy refinements, accessibility and performance improvements.

## [0.2.0] - 2026-08-21

### Added
- Cinematic interactive hero and 3D-style core system
- Scroll-controlled product storytelling sequence
- Expanded live-workflow product demo
- Conversion-focused value and audience sections
- Reduced-motion accessibility fallback

### Changed
- Reworked product messaging around delegation and outcomes
- Strengthened founding-access purchase funnel

## [0.1.0] - 2026-08-21

### Added
- Initial immersive conversion-first Ultron landing page.
- Responsive hero, capability, product-demo, proof, pricing and final CTA sections.
- Motion-based interactions and pointer-reactive visual core.
- Production security headers for the Next.js deployment.
- Repository secret-protection rules and public environment template.
- Versioning policy and release notes structure.
