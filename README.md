# Ultron Landing

Immersive, conversion-first product landing page for the Ultron AI assistant concept.

## Current release

`v0.2.0`

## Stack

- Next.js 16.3
- React 19.2
- TypeScript 7.0
- Motion 13

## Local development

```bash
npm install
npm run dev
```

## Validation

```bash
npm run typecheck
npm run build
```

## Versioning

The project follows Semantic Versioning. The canonical current version is kept in `package.json` and `VERSION`, with release history in `CHANGELOG.md` and detailed notes under `docs/versions/`.

Examples:

- `0.1.1`: visual or bug fix.
- `0.2.0`: new section, interaction, experiment or conversion feature.
- `1.0.0`: first stable public product landing release.

## Security

Never commit real `.env` files, API keys, credentials, private keys or `.vercel/` metadata. Production secrets belong in Vercel environment variables. See `SECURITY.md`.
