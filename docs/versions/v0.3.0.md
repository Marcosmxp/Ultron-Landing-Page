# Ultron Landing v0.3.0

Release date: 2026-08-21

## Theme

Immersive Particle Experience.

## Experience changes

- Added a full-viewport particle field that stays active throughout the landing page.
- Particles converge and orbit around the Ultron core while the hero is in focus.
- Mouse movement and touch gestures disturb the field naturally.
- Press/tap creates a stronger energy pulse that pushes nearby particles away.
- Scroll velocity influences particle movement and produces subtle motion trails.
- The interaction model remains immersive on mobile, tablet and desktop.

## Performance strategy

- Particle count adapts to viewport area and available hardware concurrency.
- Device pixel ratio is capped more aggressively on mobile.
- No new runtime dependency was added.
- `prefers-reduced-motion` renders the field as a static composition instead of running a continuous animation loop.

## Security

The release does not add environment variables, API credentials, third-party scripts or remote assets. Existing CSP and repository secret-protection rules remain unchanged.
